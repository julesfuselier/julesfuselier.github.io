Projet personnel, en cours

PathSide, les spots outdoor le long de la route

Un outil qui repère sommets, points de vue, cascades, lacs et sentiers autour d’un trajet, à partir des données OpenStreetMap.

Rôle
Conception et développement, seul
Période
Depuis mai 2026
Technologies
Python, API Overpass, OpenStreetMap

Ce qui était demandé

Les applications de randonnée montrent des randonnées, les GPS mènent d’un point A à un point B. Rien ne relie les deux : on passe à côté de beaux endroits sans le savoir.

Ce que j’ai fait

  • Interrogation de l’API Overpass pour cinq types de spots en une seule requête
  • Prise en charge des trois types d’objets OpenStreetMap : nœuds, chemins et relations
  • Distance réelle aux objets linéaires : le script parcourt toute la géométrie d’un sentier au lieu de s’arrêter à son centre (formule de Haversine)
  • Reprise sur erreur avec attente exponentielle, en distinguant les erreurs passagères des erreurs définitives
  • Export JSON prêt à alimenter une carte

Ce qui est livré

La phase 1, la collecte de données autour d’un point, est terminée.

Ce qui reste à faire

Phase 2 en cours : calcul de l’itinéraire A→B, filtrage par détour et affichage sur une carte Leaflet.
