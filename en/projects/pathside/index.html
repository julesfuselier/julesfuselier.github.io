Personal project, in progress

PathSide, outdoor spots along your route

A tool that finds summits, viewpoints, waterfalls, lakes and trails around a route, using OpenStreetMap data.

Role
Design and development, solo
Period
Since May 2026
Technologies
Python, API Overpass, OpenStreetMap

What was asked

Hiking apps show hikes, and navigation apps get you from A to B. Nothing connects the two: you drive past great places without knowing it.

What I did

  • Queries the Overpass API for five types of spots in a single request
  • Handles all three OpenStreetMap object types: nodes, ways and relations
  • True distance to linear objects: the script walks a trail’s full geometry instead of stopping at its centre (Haversine formula)
  • Retries with exponential backoff, telling transient failures from permanent ones
  • JSON export ready to feed a map

What is delivered

Phase 1, data collection around a point, is complete.

What is left to do

Phase 2 in progress: A→B route calculation, filtering by detour and display on a Leaflet map.
