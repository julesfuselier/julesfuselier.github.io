University project, team of 5

International mobility management platform

A PHP/MySQL web application that handles a university institute’s international mobility applications, from wish lists to ranking.

Role
Lead developer, product owner and project manager, in a Scrum team of 5
Period
2025 to 2026
Technologies
PHP, MySQL, PHPUnit, PHPStan, GitHub Actions

What was asked

Second-year project of the computer science BUT at the IUT of Aix-Marseille, for the international relations office.

What I did

  • MVC architecture with a service layer and isolated use cases (Clean Architecture)
  • Authentication with four access levels: visitor, student, administrator and super-administrator
  • Applicant ranking algorithm, centralised in one service so the formula changes in a single place
  • Scraper that authenticates against the university’s CAS and syncs the list of destinations
  • Account anonymisation for GDPR compliance
  • 195 PHPUnit tests, unit and integration, PHPStan static analysis, PSR-12 standard and GitHub Actions continuous integration

What is delivered

A complete, tested application designed for more than 1,000 students.

What is left to do

It is not used in production yet. The code is private: demo on request.
